# قنوات يوتيوب — بحث بالكلمة

تطبيق Next.js للبحث عن قنوات يوتيوب التي نشرت فيديوهات حديثة تحتوي على كلمة مفتاحية.

## الميزات

- بحث بالكلمة عبر YouTube Data API v3
- عرض القنوات كبطاقات (صورة، اسم، مشتركون)
- تفاصيل القناة من نفس طلب API (بدون استنزاف الحصة)
- حفظ القنوات في localStorage
- دعم أكثر من مفتاح API مع تدوير تلقائي

## التشغيل محلياً

```bash
npm install
npm run dev
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub
2. اربطه بـ Vercel
3. أضف متغير البيئة:

```
YOUTUBE_API_KEYS=key1,key2,key3
```

أو أضف المفاتيح من صفحة الإعدادات في التطبيق.

## استهلاك API

كل عملية بحث = **2 طلبات** فقط:
- `search.list` — فيديوهات حديثة (آخر 30 يوم)
- `channels.list` — بيانات القنوات دفعة واحدة
